# Telegram Expense Bot

Telegram-бот для личного учёта расходов на Python, aiogram 3 и SQLite.

## Возможности
- Добавление расхода сообщением, например «Кофе 300» или «Такси 1 000».
- Выбор категории через inline-кнопки.
- 10 начальных категорий и пользовательские категории.
- Статистика за текущий месяц и последние 10 расходов.
- Отдельные данные для каждого Telegram-пользователя.

## Запуск локально
1. Установите Python 3.10 или новее.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` на основе `.env.example`.
4. Вставьте новый токен бота в `BOT_TOKEN` в файле `.env`.
5. Запустите: `python bot.py`.

## Облачный запуск
Это long-running worker, а не веб-сайт. Для хостинга создайте Background Worker и задайте команду запуска `python bot.py`, добавив секретную переменную окружения `BOT_TOKEN`.

Важно: SQLite-файл должен храниться на постоянном диске/volume хостинга, иначе данные могут пропасть при пересоздании контейнера. Настройте `DB_PATH` на путь внутри постоянного volume. Не загружайте `.env` и токен в GitHub.

## Безопасность
Если токен когда-либо отправлялся в чат или попал в публичный репозиторий, отзовите его через @BotFather и используйте новый. Храните токен только в секретах хостинга.
